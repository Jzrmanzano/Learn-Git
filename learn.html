    Commands this trainer understands

    Refer to commits by branch or tag name, by ID such as C2, or relative to HEAD: HEAD~2 is two commits back, main^ is main's parent and HEAD@{1} is where HEAD was one move ago. The cheat sheet explains every command with a level to practise it.

    Making history

    • git commit -m "msg"new snapshot
    • git commit --amendreplace the last commit
    • git statuswhere you are
    • git logalso --all, main..feature
    • git show C2one commit's details

    Branches and tags

    • git switch name-c creates, - goes back
    • git checkout C2visit a commit or tag
    • git branch namealso -d, -m, -f, -a
    • git tag v1.0fixed label; -d deletes

    Combining

    • git merge namealso --no-ff, --ff-only
    • git rebase namereplay on top
    • git cherry-pick C3or a range, C2..C4
    • git merge-base a bwhere two lines split

    Undoing

    • git reset --hard refmove the branch back
    • git revert refundo with a new commit
    • git reflogeverywhere HEAD has been

    Remotes

    • git fetchdownload, move origin/…
    • git pullfetch, then merge; --rebase
    • git pushalso -u origin name, --force, --delete
    • git remote -vor add origin url
