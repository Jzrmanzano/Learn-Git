Read the graph like a transit map

Every level uses the same seven marks. Learn them once and the rest of Git is labels moving along lines.

Commit
A saved snapshot. Each one points back to the commit before it.
Line
Commits made on the same branch share a colour.
HEAD
The filled station is where you are. Your next commit attaches here.
mainBranch
A movable label. It slides forward each time you commit.
origin/mainRemote-tracking branch
Where origin's main was the last time you fetched or pushed.
v1.0Tag
A fixed label, usually for a release. It never moves.
Faded station
No longer on any branch. The reflog can still find it.

Sixteen levels, five lines

Each level sets up a small repository and gives you one goal. Hints are there when you are stuck, and progress is saved in your browser. Pick any station to jump straight in.

Made for self-paced students and computer labs

Everything runs in the browser, with no server, accounts or installs. Open it on a lab PC or a phone and start typing.

Teachers can link straight to a level, for example learn.html#level-6 for rebase or learn.html#level-15 for a rejected push, and let students work through it at their own pace. Each student's progress stays in their own browser.

LearnGit simulates commits, branches and a remote, not file contents. That keeps every level focused on how history moves.
